# Exemplo React — listagem de produtos

POC mínima que chama `GET /produtos` da Loja API e mostra os produtos em cartões.
O código que importa está em `src/App.jsx`.

## Como rodar

1. Copie `.env.example` para `.env.local` e troque `SUA_CHAVE` pela chave de acesso.
2. Instale e rode:

```bash
npm install
npm run dev
```

Abra http://localhost:5173.
